JosJis My Assets

Overview

My Assets is a wallet asset overview service within the JosJis Web3 Member Area.

It allows users to view their cryptocurrency assets using their connected wallet.

Main Features

1. JJS Balance

Display the user's JosJis token balance.

2. POL Balance

Display the user's POL balance on Polygon.

3. Other Tokens

Allow users to view other supported ERC-20 tokens.

4. Token Details

Display token information, including:

- Token name
- Token symbol
- Contract address
- Token balance
- Network

Technology

- HTML
- CSS
- JavaScript
- Reown AppKit
- Ethers.js
- Polygon Network

Data Source

Asset information will be retrieved directly from the Polygon blockchain.

No traditional user database is required.

Notes

My Assets is designed as a non-custodial wallet portfolio viewer.

It does not store or control users' private keys or funds.
