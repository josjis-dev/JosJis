JosJis Member Area

Overview

The Member Area is the central access point for the JosJis Web3 ecosystem.

Users can connect their wallets to access available and upcoming ecosystem services.

Main Services

- My Assets
- Staking
- Governance
- Utilities
- Community
- Member Benefits

Technology

- HTML
- CSS
- JavaScript
- Reown AppKit
- Ethers.js
- Polygon Network

Wallet Integration

Wallet connection is managed through the shared Web3 configuration.

Configuration file:

"../web3/web3-config.js"
