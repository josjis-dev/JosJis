How to use

  1. Obtain the exact original message and its signature from the Safe signing workflow.
  2. Enter the Safe address and select the network where it exists.
  3. Paste the exact message and signature, then press Verify Safe signature.
  4. Only treat it as verified when the result says the Safe contract accepted the signature.
Important: This first version is a Safe signature verifier, not a message-signing interface. Safe signatures can use Safe-specific message hashes and signature encodings. This page checks ERC-1271 validation methods against the supplied message; compatibility depends on how the signature was created/exported. A valid signature proves authorization by the Safe under its configured rules—it does not prove that the message's claims are true.
