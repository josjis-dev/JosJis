JosJis Assets

This directory contains the static assets used by the JosJis website.

Directory Structure

assets/
├── README.md
├── css/
├── js/
└── images/

Folders

- "css/" — Stylesheets and website design files.
- "js/" — JavaScript files used by the website.
- "images/" — Logos, icons, and other website images.

Purpose

This structure keeps website assets organized, maintainable, and easy to manage as the JosJis ecosystem grows.
